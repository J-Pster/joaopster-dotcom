# Campo visual

A área que você enxerga sem mexer os olhos, incluindo as laterais. Perder metade do campo nos dois olhos sugere problema no cérebro; perder o de um olho só sugere problema do próprio olho ou do [[Nervo|nervo]].

> [!example] Exemplo
> Para testar, você fica a 1 metro e traz um dedo da lateral para o centro; se você vê o dedo antes da pessoa, o campo dela é menor que o seu.
