# Célula beta

Célula beta é a [[Celula|célula]] das [[Ilhotas Pancreaticas|ilhotas]] do [[Pancreas|pâncreas]] que produz [[Insulina|insulina]]. No [[Diabetes Tipo 1|diabetes tipo 1]] o [[Sistema Imune|sistema imunológico]] a destrói; as [[Remedios para Diabetes|sulfonilureias]] a forçam a liberar insulina mesmo com a [[Hipoglicemia|glicose baixa]].

> [!example] Exemplo
> Quem toma [[Remedios para Diabetes|glibenclamida]] e pula o almoço corre risco de [[Hipoglicemia|hipoglicemia]] porque a célula beta continua soltando [[Insulina|insulina]] sem comida para guardar.
