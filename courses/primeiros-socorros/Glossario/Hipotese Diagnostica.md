# Hipótese Diagnóstica

Hipótese diagnóstica é uma explicação possível para o quadro, ainda não confirmada. O leigo raciocina com hipóteses ("suspeito de, não consigo descartar") para decidir o nível de urgência, nunca para dar [[Diagnostico|diagnóstico]] definitivo.

> [!example] Exemplo
> Com [[Dor Toracica|dor no peito]] e [[Diaforese|suor frio]], a hipótese "[[Infarto|infarto]]" fica de pé enquanto nenhum dado concreto a derrubar.
