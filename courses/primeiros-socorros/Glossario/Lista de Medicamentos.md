# Lista de medicamentos

Uma lista por pessoa da casa, no kit e no celular, com: nome completo e data de nascimento (e peso, se criança); doenças; [[Medicamento|medicamentos]] (nome, para quê, [[Dose|dose]] e horários conforme a receita, que você apenas copia, mais [[Fitoterapico|suplementos]] e chás); [[Alergia|alergias]]; contatos; data da última revisão (a cada mudança de receita e ao menos a cada seis meses). No celular, use o ID médico da tela de bloqueio; foto das caixas com o nome legível é alternativa rápida.
