# Peritonite
[[Infeccao|Infecção]] grave da cavidade abdominal. É o risco de reintroduzir uma alça exposta suja ou com vazamento de conteúdo intestinal: as [[Bacteria|bactérias]] são levadas para dentro do [[Abdome|abdome]]. Por isso o leigo cobre, mas não reintroduz.
