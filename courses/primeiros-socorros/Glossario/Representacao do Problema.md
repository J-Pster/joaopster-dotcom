# Representação do problema

Resumo de uma linha do caso: quem (idade, sexo, riscos relevantes) + o quê (sintoma principal com qualificadores) + contexto (evento, [[Medicamento|medicamento]], [[Comorbidade|doença de base]]) + gravidade ([[Sinais Vitais|sinais vitais]], aspecto geral). Se você não consegue escrever a linha, ainda falta dado; a cada reavaliação, refaça a frase para não ficar preso à anterior.

## Qualificadores Semanticos
Pares de opostos que descrevem a situação: agudo x [[Agudo e Cronico|crônico]], súbito x gradual, contínuo x intermitente, localizado x difuso, [[Febre|febril]] x [[Afebril|afebril]], estável x instável. Exemplo bom: "[[Dor Toracica|dor torácica]] em aperto, súbita, há 30 minutos, com [[Diaforese|sudorese]]".
