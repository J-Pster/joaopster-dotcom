# Líquor

Líquido que envolve o cérebro. Saindo claro pelo nariz ou pelo ouvido após pancada na cabeça, sugere [[Fratura de Base de Crânio|fratura de base de crânio]]. Não tampone: deixe escoar, cubra com gaze solta sem pressionar e acione o [[SAMU]].
