# Glicemia média estimada

Estimativa da glicemia média dos últimos 2 a 3 meses, calculada a partir da [[Hemoglobina Glicada|hemoglobina glicada]]. Uma HbA1c de 7% corresponde a uma média de cerca de 154 mg/dL, mas a média esconde oscilações.

> [!example] Exemplo
> Uma [[Hemoglobina Glicada|HbA1c]] de 8% equivale a uma glicemia média de cerca de 183 mg/dL.
