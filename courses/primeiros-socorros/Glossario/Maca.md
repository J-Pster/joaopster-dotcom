# Maca

Superfície firme, em geral com alças, usada para carregar uma pessoa deitada com a menor sacudida possível. Em [[Cuidado Prolongado|cuidado prolongado]], a maca (ou uma improvisada) permite levar a vítima até o [[Ponto de Encontro|ponto de encontro]] com 4 pessoas se revezando.

> [!example] Exemplo
> Para atravessar uma ponte alagada, quatro vizinhos improvisam uma maca com uma lona e dois cabos de vassoura, e se revezam a cada poucos minutos para não deixar a vítima cair.
