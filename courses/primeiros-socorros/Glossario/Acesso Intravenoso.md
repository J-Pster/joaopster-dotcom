# Acesso intravenoso

[[Cateter]] fino colocado dentro de uma [[Veia|veia]] para dar líquidos e [[Medicamento|remédios]] direto no sangue. É procedimento de profissional: exige treino para achar a veia sem ferir o que está em volta.

> [!example] Exemplo
> Num ferido em [[Choque|choque]], a equipe do [[SAMU]] coloca um acesso na [[Veia|veia]] do braço para repor volume.
