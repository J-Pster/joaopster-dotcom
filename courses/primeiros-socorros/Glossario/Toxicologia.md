# Toxicologia

Área da medicina que estuda os [[Veneno|venenos]] e as [[Intoxicacao|intoxicações]]. Os toxicologistas dos centros como o [[CIATox]] orientam por telefone a conduta para cada produto e cada quantidade.

> [!example] Exemplo
> Ao ligar para o [[CIATox]], o toxicologista pergunta idade, peso, produto, quantidade e hora para dizer o que fazer.
