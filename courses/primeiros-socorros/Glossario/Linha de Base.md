# Linha de base

O valor normal daquela pessoa, e não o da tabela: a primeira medida que você fez e o que ela costuma ter. Um atleta com [[Frequencia Cardiaca|FC]] de repouso 50 está acelerado com 90; um idoso [[Hipertensao Arterial|hipertenso]] que cai de 150/90 para 110/70 caiu muito, mesmo que 110/70 pareça normal. A [[Tendencia|tendência]] se lê comparando com a linha de base.
