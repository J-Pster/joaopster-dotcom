# Cintilografia

Exame de imagem que usa uma quantidade muito pequena de substância radioativa para mostrar como o ar e o sangue chegam a um [[Orgao|órgão]]. No pulmão, é uma das opções de imagem para confirmar embolia.

> [!example] Exemplo
> Quando uma pessoa não pode receber o contraste da [[Tomografia|tomografia]], a equipe pode usar a cintilografia para investigar a embolia.
