# Isocoria

[[Pupila|Pupilas]] do mesmo tamanho nos dois olhos, o que é o normal. O contrário se chama [[Anisocoria|anisocoria]].

> [!example] Exemplo
> Ao iluminar de lado, você anota "isocoria, 3 mm nos dois olhos", e isso serve de base para comparar depois.
