# C-A-B
Compressões, via aérea, respiração: sequência das [[Diretriz|diretrizes]] de [[RCP]] ([[AHA]]) para [[Parada Cardiaca|parada cardíaca]] súbita de causa clínica. O [[Oxigenio|oxigênio]] ainda está no sangue e o que parou foi a bomba, então a prioridade é comprimir. Responde a um problema diferente do [[XABCDE]], que é de [[Trauma|trauma]] com [[Hemorragia|sangramento]] externo.
