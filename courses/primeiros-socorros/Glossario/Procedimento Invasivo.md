# Procedimento invasivo

Ato que atravessa a pele ou entra no corpo, como injetar, [[Sutura|suturar]], puncionar ou abrir uma via aérea. É exclusivo de profissional; os [[Protocolo|protocolos]] o explicam para o leigo entender o que a equipe fará, não para ele fazer.

> [!example] Exemplo
> Descompressão com [[Agulha|agulha]] no [[Torax|tórax]] é procedimento invasivo: o leigo entende por que a equipe faz, mas não faz.
