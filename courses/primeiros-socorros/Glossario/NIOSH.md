# NIOSH

Instituto de segurança e saúde no trabalho dos Estados Unidos. Ele definiu 23 kg como a carga ideal de levantamento seguro para a maioria dos trabalhadores, em condições ideais. Serve de régua para saber quantas pessoas são necessárias para carregar alguém.

> [!example] Exemplo
> Para carregar uma vítima de 70 kg dentro do limite de 23 kg por pessoa, são necessárias 4 pessoas.
