# Estado Basal

Como a pessoa é no dia a dia: como fala, pensa, anda e age quando está bem. É a referência para perceber mudança. Pergunta-chave diante de [[Confusao Mental|confusão]]: qual é o basal dessa pessoa?

> [!example] Exemplo
> Dona Zélia sempre foi falante; hoje está calada e [[Sonolencia|sonolenta]]. O basal dela é falante, então a mudança é grande e deve ser investigada.
