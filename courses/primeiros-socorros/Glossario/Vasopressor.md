# Vasopressor

[[Medicamento]] que contrai os vasos para subir a pressão. É de uso hospitalar ou de equipe médica; o leigo não usa, mas saber que existe ajuda a entender por que o [[Choque|choque]] [[Descompensacao|descompensado]] precisa de hospital.

> [!example] Exemplo
> Num [[Tipos de Choque|choque séptico]], o hospital usa vasopressor por [[Veia|veia]] para manter a pressão. O leigo não tem como fazer isso: o papel dele é reconhecer cedo e acionar o [[SAMU]] para que o tratamento comece a tempo.
