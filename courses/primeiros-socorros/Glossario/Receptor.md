# Receptor

Receptor é uma "fechadura" na superfície de uma [[Celula|célula]] à qual uma substância se encaixa para provocar um efeito. Opioides se encaixam em receptores do cérebro e freiam a respiração.

> [!example] Exemplo
> Os opioides ocupam receptores no [[Tronco Cerebral|tronco cerebral]] e reduzem o impulso de respirar; a [[Naloxona|naloxona]] os desloca desses receptores.
