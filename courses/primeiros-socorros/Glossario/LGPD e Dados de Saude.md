# LGPD e dados de saúde

Dados de saúde são dados pessoais sensíveis na Lei Geral de Proteção de Dados (conhecimento geral, o artigo não foi reconfirmado). Na prática: compartilhe a ficha com quem presta cuidado (profissional, escola, [[Cuidador|cuidador]]), não publique em redes sociais, não envie por canal aberto sem necessidade, guarde cópias com cuidado e retire do celular emprestado. Crianças e idosos têm responsáveis legais para decidir sobre os dados.
