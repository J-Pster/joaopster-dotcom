# Lote

Lote é o grupo de tiras fabricadas juntas. Cada lote pode ter pequenas diferenças, e a ISO exige testar três lotes diferentes para provar a [[Exatidao|exatidão]] do aparelho.

> [!example] Exemplo
> Duas caixas de tiras com lotes diferentes podem dar leituras ligeiramente diferentes na mesma gota.
