# FSx for Windows File Server

O FSx for Windows File Server entrega servidores de arquivos Windows gerenciados, com sistema de arquivos nativo, protocolo SMB, autenticação pelo Active Directory e permissões em ACLs NTFS. Pode ser Single-AZ ou Multi-AZ (com servidor standby em outra AZ) e usar SSD ou HDD. Existe para migrar aplicações e pastas de rede Windows para a nuvem sem reescrever nada.

> [!example] Exemplo
> Uma empresa migra a unidade de rede dos departamentos para um FSx for Windows Multi-AZ ligado ao seu AD.
