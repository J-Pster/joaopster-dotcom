# Local Gateway

O local gateway (LGW) roteia o tráfego entre um Outpost em rack e a rede local do cliente. Existe para que as instâncias do Outpost conversem com os sistemas do datacenter com baixa latência, sem passar pela Região.

> [!example] Exemplo
> Uma instância no Outpost acessa um banco local pelo local gateway.
