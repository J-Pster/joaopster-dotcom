# Consolidated Billing

Recurso do Organizations em que a conta de gerenciamento recebe uma única fatura, somando o uso de todas as contas membros. O uso é agregado para fins de descontos por volume, e descontos de Reserved Instances e Savings Plans podem ser compartilhados entre as contas. A separação dos custos por conta continua visível nos relatórios.

> [!example] Exemplo
> Duas contas que somam 80 TB de armazenamento podem alcançar uma faixa de preço menor do que cada uma teria sozinha.
