# Sub-rede Privada

Sub-rede privada é a que não tem rota para um Internet Gateway, então nada da internet inicia conexão com os recursos dela. Para sair (atualizações, APIs), usa-se um NAT gateway ou endpoints. É o lugar certo para aplicação e banco de dados, por reduzir a superfície de ataque.

> [!example] Exemplo
> As instâncias EC2 da aplicação ficam em sub-redes privadas e saem para a internet por um NAT gateway da própria AZ.
