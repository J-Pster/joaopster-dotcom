# EC2

Serviço de servidores virtuais da AWS. Uma instância roda em uma AZ, e o cliente gerencia o sistema operacional, o software e o security group. É o serviço IaaS por excelência. Detalhado no Módulo 9.

> [!example] Exemplo
> Uma instância m7g.large em us-east-1a rodando a aplicação web.

Veja também: [[Auto Scaling Group]], [[EBS]], [[Zona de Disponibilidade]]
