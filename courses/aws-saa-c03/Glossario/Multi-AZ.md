# Multi-AZ

Multi-AZ é a configuração em que o serviço mantém componentes em mais de uma Zona de Disponibilidade para continuar funcionando se uma zona falhar. Aumenta a disponibilidade ao custo de mais recursos e, em bancos gerenciados como o RDS, traz failover automático, embora possa haver breve interrupção. Na prova é a resposta típica para alta disponibilidade; para escalar leitura, em geral se usa read replica.

> [!example] Exemplo
> Um banco RDS em Multi-AZ mantém uma réplica em outra zona e promove essa réplica quando a primária falha.
