# Cutover

O cutover é o momento em que a produção passa da origem para o destino: o tráfego é redirecionado e o ambiente antigo deixa de ser o principal. Existe como o ponto de maior risco da migração, por isso se testa antes e se mantém a origem disponível para um possível retorno.

> [!example] Exemplo
> No sábado, a equipe para a origem, aplica os últimos dados e aponta o DNS para a AWS.
