# OWASP Top 10

O OWASP Top 10 é a lista da fundação OWASP com as categorias mais críticas de risco em aplicações web, como injeção, autenticação quebrada e configuração insegura. Serve de referência comum de ameaças, e managed rule groups do WAF, como o Core rule set, cobrem parte delas.

> [!example] Exemplo
> Injeção de SQL é uma categoria clássica; o managed rule group de SQL database do WAF mira esse padrão.
