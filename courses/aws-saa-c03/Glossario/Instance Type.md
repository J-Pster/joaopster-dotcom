# Instance Type

Combinação de CPU, memória, armazenamento e rede que define uma instância EC2, escrita como família, geração, opções e tamanho (por exemplo m6gd.xlarge). Escolher o tipo certo decide desempenho e custo, porque cada família é otimizada para um perfil de carga.

> [!example] Exemplo
> Para um banco em memória, escolhe-se a família r (memória otimizada); para um servidor de renderização, a família c (computação otimizada).
