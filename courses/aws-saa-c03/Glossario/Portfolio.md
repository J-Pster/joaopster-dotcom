# Portfolio

Portfólio é uma coleção de produtos do AWS Service Catalog, com regras de acesso e restrições. Existe para organizar o que cada grupo de usuários pode lançar. Pode ser compartilhado com outras contas ou com a organização.

> [!example] Exemplo
> O portfólio Plataforma contém os produtos banco padrão e fila padrão, liberados para os desenvolvedores.
