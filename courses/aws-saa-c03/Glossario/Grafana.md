# Grafana

Grafana é uma ferramenta de código aberto para criar painéis e visualizações a partir de várias fontes de dados, como Prometheus, CloudWatch e X-Ray. Existe para unificar a visualização de métricas de origens diferentes. Na AWS, existe uma versão gerenciada.

> [!example] Exemplo
> Um painel Grafana junta métricas do CloudWatch e do Prometheus em uma tela única.
