# FSx for NetApp ONTAP

O FSx for NetApp ONTAP entrega o sistema de arquivos NetApp ONTAP como serviço gerenciado, acessível por NFS, SMB, iSCSI e NVMe, com tiering automático para uma capacity pool mais barata, snapshots, clones e replicação SnapMirror. Existe para migrar ambientes NetApp e consolidar vários protocolos em um só serviço, sem mudar aplicações nem rotinas de gestão.

> [!example] Exemplo
> Uma empresa com NetApp local, usando NFS, SMB e iSCSI, migra para o FSx for ONTAP e mantém a replicação SnapMirror para outra Região.
