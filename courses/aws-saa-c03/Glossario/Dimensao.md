# Dimensao

Dimensão é um par nome e valor que identifica de forma única uma métrica dentro de um namespace. Existe para separar a mesma métrica por recurso, por exemplo por instância ou por grupo de Auto Scaling. Combinações diferentes de dimensões geram métricas diferentes, e cada uma é cobrada à parte quando é personalizada.

> [!example] Exemplo
> CPUUtilization com InstanceId=i-0abc é uma métrica; com AutoScalingGroupName=web é outra.
