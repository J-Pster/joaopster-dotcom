# Launch Constraint

Launch constraint é uma restrição do Service Catalog que define o papel IAM usado para criar os recursos de um produto. Existe para que o usuário final possa lançar o produto sem ter permissão direta para criar os recursos.

> [!example] Exemplo
> Desenvolvedores lançam o produto banco padrão, e quem cria o RDS é o papel de lançamento.
