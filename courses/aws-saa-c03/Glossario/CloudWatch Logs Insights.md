# CloudWatch Logs Insights

O CloudWatch Logs Insights é uma linguagem de consulta interativa para pesquisar e analisar logs armazenados no CloudWatch Logs. Existe para investigar incidentes sem exportar os logs para outra ferramenta. A cobrança é por quantidade de dados examinados.

> [!example] Exemplo
> Uma consulta agrupa erros por mensagem nos últimos 30 minutos para achar a causa de um pico.
