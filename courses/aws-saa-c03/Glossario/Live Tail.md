# Live Tail

É o recurso do CloudWatch Logs que mostra os eventos de log em tempo real no console, quase como um tail -f. Existe para acompanhar um deploy ou um incidente sem esperar a consulta do Logs Insights.

> [!example] Exemplo
> Durante um deploy, a equipe acompanha os erros chegando ao log group no mesmo instante.
