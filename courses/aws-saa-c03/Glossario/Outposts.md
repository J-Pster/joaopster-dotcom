# Outposts

Serviço totalmente gerenciado que instala hardware da AWS (racks de 42U ou servidores de 1U ou 2U) nas instalações do cliente, operado como parte de uma Região. Permite usar as mesmas APIs e ferramentas da AWS com latência local e dados que precisam ficar no local. Não é uma Região independente.

> [!example] Exemplo
> Uma fábrica roda EC2 e RDS na própria planta, gerenciados pela AWS, para responder em poucos milissegundos às máquinas.
