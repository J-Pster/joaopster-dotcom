# Distributor

O Distributor empacota e distribui software para nós gerenciados, instalando ou atualizando pacotes sob demanda ou por agenda via State Manager.

> [!example] Exemplo
> Um agente corporativo é distribuído a todos os servidores por um pacote do Distributor.
