# Aurora

Banco relacional compatível com MySQL e PostgreSQL, da AWS, com armazenamento distribuído em várias AZs. Detalhado no Módulo 13.

> [!example] Exemplo
> Um cluster Aurora PostgreSQL com réplicas de leitura.
