# AWS Transform

O AWS Transform é um serviço da AWS que usa agentes de IA para acelerar a migração e a modernização de infraestrutura, aplicações e código: descoberta e planejamento de servidores (VMware, Hyper-V e outros), rehost para o EC2, modernização de aplicações .NET e de mainframe. Ele é um serviço próprio, e não um novo nome do Application Migration Service. Existe para reunir descoberta, planejamento e execução de migrações e modernizações em um só lugar.

> [!example] Exemplo
> Uma empresa usa o AWS Transform para inventariar o ambiente VMware, montar as ondas de migração e executar o rehost dos servidores para o EC2.
