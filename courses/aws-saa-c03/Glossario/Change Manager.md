# Change Manager

O Change Manager é a capacidade do Systems Manager para solicitar, aprovar e executar mudanças operacionais. Está fechado para novos clientes (verificado em novembro de 2026), mas aparece em material antigo.

> [!example] Exemplo
> Material antigo recomenda o Change Manager para aprovar mudanças, mas contas novas não conseguem ativá-lo.
