# Active Directory

Serviço de diretório da Microsoft que guarda usuários, grupos e computadores de uma organização e autentica por Kerberos e LDAP. É a base dos domínios Windows e aplica políticas de grupo (Group Policy). Na AWS, o Directory Service oferece AD gerenciado e formas de usar um AD existente.

> [!example] Exemplo
> Uma aplicação SharePoint migrada para a AWS precisa de um domínio Active Directory para autenticar os usuários.
