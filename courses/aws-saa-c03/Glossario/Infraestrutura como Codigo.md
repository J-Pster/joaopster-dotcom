# Infraestrutura como Codigo

Infraestrutura como código é a prática de descrever a infraestrutura em arquivos versionados e criá-la por uma ferramenta, em vez de clicar no console. Existe para dar repetibilidade, revisão e rastreabilidade. Na AWS, o CloudFormation é a ferramenta nativa; o OpenTofu e o Terraform são alternativas.

> [!example] Exemplo
> O mesmo template cria os ambientes de homologação e produção, mudando apenas parâmetros.
