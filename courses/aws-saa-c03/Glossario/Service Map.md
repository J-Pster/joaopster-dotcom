# Service Map

Service map é a visualização do X-Ray que mostra os serviços de uma aplicação como nós e as chamadas entre eles como arestas, com latência e taxa de erro. Existe para entender dependências e achar o ponto problemático rapidamente.

> [!example] Exemplo
> O mapa mostra um nó de banco de dados em vermelho, indicando erros nas chamadas vindas da API.
