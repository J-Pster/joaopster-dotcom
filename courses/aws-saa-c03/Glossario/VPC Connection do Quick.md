# VPC Connection do Quick

Recurso do Amazon Quick que leva o serviço até uma sub-rede privada da sua VPC, com um security group próprio, para ler bancos como RDS ou Redshift sem expô-los à internet.

> [!example] Exemplo
> O Quick lê um RDS em sub-rede privada por uma VPC connection com o security group liberando a porta do banco.
