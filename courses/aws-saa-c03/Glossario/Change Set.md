# Change Set

Change set é uma prévia das alterações que uma atualização faria em uma stack, indicando o que seria adicionado, modificado, substituído ou removido. Existe para evitar surpresas, como a substituição de um banco de dados. Só aplica a mudança quando você o executa.

> [!example] Exemplo
> O change set mostra Replacement igual a True para o banco, e a equipe cancela a atualização.
