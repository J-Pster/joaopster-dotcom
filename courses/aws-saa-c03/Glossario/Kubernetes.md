# Kubernetes

Kubernetes é o orquestrador de containers de código aberto mais usado, com um modelo de API padronizado: pods, deployments, services e ingress. Sua vantagem é a portabilidade entre nuvens e data centers e um grande ecossistema. O custo é a complexidade operacional, que o EKS reduz ao gerenciar o plano de controle.

> [!example] Exemplo
> Uma empresa multicloud usa os mesmos manifestos Kubernetes no EKS e em seu data center.
