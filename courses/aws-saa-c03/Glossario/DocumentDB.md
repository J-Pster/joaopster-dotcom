# DocumentDB

Banco de documentos gerenciado da AWS com API compatível com o MongoDB. Armazena documentos JSON, com armazenamento compartilhado replicado em três AZs e até 15 réplicas de leitura. Serve para migrar aplicações MongoDB com poucas mudanças.

> [!example] Exemplo
> Uma aplicação que já usa o driver do MongoDB passa a falar com o DocumentDB sem reescrever o acesso a dados.
