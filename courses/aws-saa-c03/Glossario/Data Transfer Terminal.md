# Data Transfer Terminal

O Data Transfer Terminal é uma instalação física da AWS para onde o cliente leva seu próprio armazenamento e o conecta à rede da AWS em alta velocidade. A documentação o aponta como alternativa ao Snowball para clientes com suporte Enterprise. Detalhes de locais e preços não foram confirmados.

> [!example] Exemplo
> Uma empresa leva discos a um terminal da AWS para subir centenas de terabytes de uma vez.
