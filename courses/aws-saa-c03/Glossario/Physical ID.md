# Physical ID

Physical ID é o identificador real do recurso criado pelo CloudFormation, como o ID de uma instância ou o nome de um bucket. Muda quando o recurso é substituído em uma atualização.

> [!example] Exemplo
> O logical ID Banco corresponde ao physical ID db-ABC123.
