# Keyspaces

Serviço de banco wide-column serverless, compatível com o Apache Cassandra e com a linguagem CQL. Replica os dados em três AZs e escala sozinho, para quem quer rodar cargas Cassandra sem administrar nós.

> [!example] Exemplo
> Uma empresa com um cluster Cassandra próprio migra para o Keyspaces e mantém o código CQL.
