# Rekognition Custom Labels

O Rekognition Custom Labels permite treinar um modelo de visão com as suas próprias imagens rotuladas (AutoML), para reconhecer objetos ou cenas específicos do seu negócio. Existe porque o Rekognition padrão não conhece, por exemplo, as peças de uma fábrica. O modelo treinado é cobrado por hora de unidade de inferência enquanto estiver iniciado, então deve ser parado quando não for usado.

> [!example] Exemplo
> Uma fábrica treina um modelo para distinguir peças defeituosas das boas e inicia o modelo apenas durante o turno de inspeção.
