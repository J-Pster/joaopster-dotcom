# Maintenance Window

A janela de manutenção do Systems Manager define quando tarefas como Run Command, Automation, Lambda ou Step Functions podem rodar nos nós. Existe para limitar o risco de mudanças a horários combinados.

> [!example] Exemplo
> Os patches de produção só são instalados na janela de domingo às 2h.

Veja também: [[Automation]], [[Patch Manager]], [[Run Command]]
