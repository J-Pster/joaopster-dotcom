# Rekognition

O Amazon Rekognition é o serviço gerenciado de visão computacional: analisa imagens e vídeos para detectar objetos, cenas, texto, rostos, celebridades e conteúdo impróprio. Existe para que a aplicação reconheça o que há em uma imagem sem treinar uma rede neural. Vídeo armazenado é processado de forma assíncrona, com aviso por SNS ao terminar.

> [!example] Exemplo
> Um app de fotos envia cada upload ao Rekognition para detectar conteúdo impróprio antes de publicar.
