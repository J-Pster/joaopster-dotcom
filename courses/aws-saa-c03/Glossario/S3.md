# S3

O Amazon S3 é o serviço de armazenamento de objetos da AWS, com durabilidade de 11 noves, capacidade praticamente ilimitada e cobrança por uso. Guarda qualquer tipo de arquivo em buckets (regionais, com nome único globalmente) e se integra a quase todos os serviços, o que o torna a base dos data lakes, backups e sites estáticos. Existe como armazenamento barato e durável desacoplado de qualquer servidor, e na prova é a resposta padrão para dados não estruturados.

> [!example] Exemplo
> Um data lake guarda os logs brutos em um bucket do S3 e várias ferramentas leem os mesmos arquivos.
