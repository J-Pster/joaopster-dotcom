# Model Registry

O SageMaker Model Registry versiona modelos, rastreia artefatos e linhagem, tem fluxo de aprovação e apoia a implantação entre contas. Existe para governar a promoção de modelos do treino à produção.

> [!example] Exemplo
> Um modelo novo entra no registro como 'pendente'; após aprovação, o pipeline o implanta no endpoint de produção.
