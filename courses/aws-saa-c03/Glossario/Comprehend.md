# Comprehend

O Amazon Comprehend é o serviço gerenciado de processamento de linguagem natural da AWS: recebe texto e devolve sentimento, entidades, frases-chave, idioma dominante, tópicos e dados pessoais (PII). Existe para que quem não sabe treinar modelos de linguagem ainda possa extrair significado de texto por uma chamada de API. Oferece modo síncrono para textos curtos e jobs assíncronos para volumes grandes em S3.

> [!example] Exemplo
> Uma loja manda os comentários de clientes ao Comprehend e recebe, para cada um, o sentimento (positivo, negativo, neutro ou misto).
