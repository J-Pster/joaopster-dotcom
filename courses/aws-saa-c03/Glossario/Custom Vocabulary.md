# Custom Vocabulary

O Custom Vocabulary é uma lista de palavras e expressões (nomes próprios, siglas, termos técnicos) que o Amazon Transcribe passa a reconhecer com mais precisão. Existe porque o modelo padrão erra palavras raras ou específicas de um domínio. É uma personalização leve, sem treinar modelo.

> [!example] Exemplo
> Uma clínica inclui nomes de medicamentos no vocabulário personalizado para a transcrição acertar os termos.
