# SPICE

O SPICE é o mecanismo de cálculo em memória do Quick: os dados importados ficam nele, e as consultas dos painéis rodam com rapidez sem sobrecarregar a fonte original. A alternativa é a consulta direta, que sempre lê os dados frescos da fonte. Existe para tornar painéis rápidos e baratos para a fonte.

> [!example] Exemplo
> Os dados de vendas são importados para o SPICE toda noite, e os painéis respondem em segundos durante o dia.
