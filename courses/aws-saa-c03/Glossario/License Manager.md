# License Manager

O AWS License Manager controla licenças de software de fornecedores (BYOL) em instâncias AWS e on-premises, com regras por vCPU, núcleo, soquete ou instância. Com limite rígido, bloqueia lançamentos acima das licenças compradas, e pode ser compartilhado na organização.

> [!example] Exemplo
> A empresa limita o software a 200 vCPUs, e o 201º lançamento é bloqueado.
