# AWS App2Container

O AWS App2Container foi uma ferramenta de linha de comando que analisava aplicações Java e .NET em servidores e gerava imagens e artefatos de deploy para ECS ou EKS. A AWS encerrou o serviço para novos clientes, e a documentação atual orienta outros caminhos, mas o nome ainda aparece em simulados antigos. Para a prova, saiba o que ele fazia e que não é mais a recomendação atual.

> [!example] Exemplo
> Um simulado antigo pergunta qual ferramenta containeriza uma aplicação Java sem o código-fonte, e a resposta esperada é o App2Container.
