# Hybrid Activation

Ativação híbrida é o mecanismo para registrar servidores on-premises ou de outras nuvens como nós gerenciados do Systems Manager, usando um código e um ID de ativação. Os nós aparecem com o prefixo mi-.

> [!example] Exemplo
> Servidores do datacenter são registrados com uma ativação híbrida e passam a receber patches.
