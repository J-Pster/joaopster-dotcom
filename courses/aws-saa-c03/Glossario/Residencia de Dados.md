# Residencia de Dados

Exigência legal, contratual ou política de que os dados fiquem fisicamente em um país ou bloco. Na AWS se atende escolhendo a Região no local exigido e não replicando para fora. SCPs podem impedir o uso de Regiões não aprovadas.

> [!example] Exemplo
> Dados de clientes da UE em eu-central-1, sem replicação para outras Regiões.
