# Amplify

O AWS Amplify é um conjunto de ferramentas e serviços para desenvolvedores de front-end e mobile construírem, hospedarem e conectarem aplicações web e móveis na AWS. O Amplify Hosting publica o app a partir de um repositório Git com deploy contínuo, distribuição por CDN, ambientes por branch e pré-visualizações de pull request; o backend (Gen 2) é definido em TypeScript. Na prova aparece como a resposta para times de front-end com pouco conhecimento de infraestrutura.

> [!example] Exemplo
> Um time conecta o repositório GitHub de um app React ao Amplify Hosting, e cada push na branch principal compila e publica o site automaticamente.
