# Dedicated Host

Servidor físico inteiro alocado a uma única conta, com visibilidade de soquetes e núcleos e controle de posicionamento. É a opção para usar licenças de software por soquete ou núcleo (BYOL) e para requisitos de conformidade que exigem hardware dedicado. O custo é pagar pelo host inteiro.

> [!example] Exemplo
> Uma empresa com licenças de banco de dados por soquete aloca um Dedicated Host, lança as instâncias nele e comprova a contagem de soquetes em uma auditoria.
