# Redis

Motor de dados em memória, de código aberto, com estruturas ricas (listas, conjuntos, mapas, conjuntos ordenados), replicação e persistência opcional. É um dos motores oferecidos pelo ElastiCache e a base do MemoryDB.

> [!example] Exemplo
> Um jogo usa um conjunto ordenado do Redis para manter o ranking dos jogadores atualizado.

Veja também: [[ElastiCache]], [[Memcached]], [[MemoryDB]], [[Valkey]]
