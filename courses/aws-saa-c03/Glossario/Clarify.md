# Clarify

O SageMaker Clarify detecta possível viés em dados e modelos e ajuda a explicar as previsões. A AWS marcou o recurso como fechado a novos clientes, mas ele ainda é a resposta de prova para 'viés e explicabilidade'.

> [!example] Exemplo
> Um banco usa o Clarify para verificar se um modelo de crédito trata grupos de forma desigual e quais variáveis mais pesaram em cada decisão.
