# Migracao Homogenea

A migração homogênea mantém o mesmo motor de banco entre a origem e o destino (por exemplo, PostgreSQL para PostgreSQL). Existe como o caso mais simples: não há conversão de esquema, e as ferramentas nativas do motor ou o DMS resolvem.

> [!example] Exemplo
> MySQL local migrado para o RDS for MySQL.
