# VMware Cloud on AWS

Serviço que roda o ambiente VMware (vSphere) em infraestrutura da AWS, usado para migrar ou estender cargas VMware sem reescrevê-las. Aparece em cenários de migração com a ideia de realocar (relocate) máquinas virtuais. É diferente de Outposts, que leva hardware AWS para o cliente.

> [!example] Exemplo
> Uma empresa com centenas de VMs no vSphere move o ambiente inteiro para a nuvem mantendo as ferramentas VMware.
