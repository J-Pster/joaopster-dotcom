# Fleet Manager

O Fleet Manager é a capacidade do Systems Manager para administrar nós pelo console, com navegação de arquivos, usuários e registro, sem SSH nem RDP.

> [!example] Exemplo
> Um administrador consulta o registro de eventos de uma instância pelo console.
