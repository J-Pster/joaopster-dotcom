# Lex

O Amazon Lex é o serviço gerenciado para criar chatbots e assistentes de voz: entende o que a pessoa quer (intent), extrai os dados necessários (slots) e pode chamar uma função Lambda para validar e executar o pedido. Existe para dar à aplicação uma conversa guiada em texto ou voz sem montar um motor de linguagem. Integra-se ao Amazon Connect para atendimento por telefone.

> [!example] Exemplo
> Um bot do Lex de uma pizzaria identifica o intent PedirPizza, preenche os slots sabor e tamanho e chama uma Lambda para registrar o pedido.
