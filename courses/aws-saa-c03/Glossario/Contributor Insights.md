# Contributor Insights

É o recurso do CloudWatch que analisa logs e mostra os principais contribuintes de um padrão, como os IPs que mais geram erros. Existe para achar rapidamente quem causa a maior parte de um problema.

> [!example] Exemplo
> Descobrir que 3 endereços IP geram 80% das requisições bloqueadas de uma API.
