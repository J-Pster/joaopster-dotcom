# Timestream

Banco de séries temporais da AWS, otimizado para dados em que o tempo é o eixo (telemetria, métricas, cliques). O Timestream for LiveAnalytics está fechado a novos clientes; para cargas novas existe o Timestream for InfluxDB.

> [!example] Exemplo
> Milhões de leituras de sensores por minuto, consultadas como média por janela de 5 minutos.
