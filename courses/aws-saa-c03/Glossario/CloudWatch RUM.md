# CloudWatch RUM

O CloudWatch RUM coleta dados de desempenho e erros diretamente dos navegadores dos usuários reais, por meio de um trecho de JavaScript. Existe para medir a experiência real (tempo de carregamento, erros no cliente), que testes sintéticos não capturam.

> [!example] Exemplo
> O RUM mostra que usuários em uma região específica têm carregamento 3 vezes mais lento.
