# FSx

O Amazon FSx é uma família de serviços gerenciados que entregam sistemas de arquivos de terceiros populares: Windows File Server, Lustre, NetApp ONTAP e OpenZFS. Existe para quem precisa de um protocolo, de um recurso ou de um desempenho específico (SMB com Active Directory, HPC, multiprotocolo, ZFS) sem operar os servidores.

> [!example] Exemplo
> Uma empresa escolhe FSx for Windows para sua pasta de rede e FSx for Lustre para um pipeline de machine learning.

Veja também: [[EFS]], [[FSx for Lustre]], [[FSx for NetApp ONTAP]], [[FSx for OpenZFS]], [[FSx for Windows File Server]]
