# Directory Service

Família de serviços da AWS para usar o Active Directory na nuvem. O AWS Managed Microsoft AD roda um Active Directory real, gerenciado pela AWS, com um par de domain controllers em zonas diferentes, trusts e compartilhamento entre contas. As outras opções são o AD Connector e o Simple AD.

> [!example] Exemplo
> Uma empresa cria um Managed Microsoft AD, estabelece um trust com o AD local e ingressa instâncias EC2 no domínio.

Veja também: [[AD Connector]], [[Active Directory]], [[Simple AD]]
