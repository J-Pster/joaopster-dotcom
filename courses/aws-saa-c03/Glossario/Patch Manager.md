# Patch Manager

O Patch Manager automatiza a instalação de correções de sistema operacional e aplicações em nós gerenciados, usando patch baselines e patch groups. Costuma rodar dentro de uma janela de manutenção e gera relatório de conformidade.

> [!example] Exemplo
> Os servidores de produção recebem correções críticas todo domingo às 2h.
