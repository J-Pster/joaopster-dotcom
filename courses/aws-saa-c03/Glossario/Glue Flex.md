# Glue Flex

Flex é uma classe de execução dos jobs do Glue para cargas sem urgência, com preço por DPU-hora menor que o Standard, porque o início pode demorar. Existe para ETL noturno ou de teste que não precisa de resposta imediata.

> [!example] Exemplo
> Um ETL que roda de madrugada e só é lido de manhã usa Flex para gastar menos.
