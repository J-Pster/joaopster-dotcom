# Application Load Balancer

O Application Load Balancer é o balanceador de camada 7 do Elastic Load Balancing, regional, que lê a requisição HTTP/HTTPS e roteia por caminho, host, cabeçalho ou query string. Termina a conexão do cliente, informa o IP original em X-Forwarded-For e aceita WAF, autenticação e Lambda como destino, mas não aceita Elastic IP (para IP fixo, use o NLB). A prova o pede para roteamento baseado em conteúdo e microsserviços.

> [!example] Exemplo
> Regras de listener enviam /clientes e /pedidos para serviços ECS diferentes.
