# LDAP

Protocolo para consultar e modificar diretórios, usado para procurar usuários e grupos no Active Directory e em outros diretórios. A versão segura usa SSL ou TLS. Aplicações Linux e ferramentas de autenticação costumam usá-lo para falar com o AD.

> [!example] Exemplo
> Um servidor Linux consulta o Managed Microsoft AD por LDAP seguro para autenticar quem entra por SSH.
