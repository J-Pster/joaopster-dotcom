# Data Pipeline

O AWS Data Pipeline é um serviço legado para orquestrar a movimentação e a transformação de dados agendadas entre serviços. Hoje as respostas atuais são Glue, Step Functions ou MWAA. Aparece na prova como distrator ou como o serviço antigo.
