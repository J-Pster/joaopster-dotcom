# Configuration Item

Registro do Config com a configuração de um recurso num momento, incluindo suas relações com outros recursos. A sequência desses itens forma o histórico de configuração. Gravar mais tipos de recurso gera mais itens e aumenta o custo.

> [!example] Exemplo
> Cada alteração em um security group gera um novo item de configuração, e o histórico mostra como ele estava na semana passada.
