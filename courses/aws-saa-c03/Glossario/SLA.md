# SLA

O SLA é o compromisso contratual de nível de serviço, com consequência financeira, como crédito ou multa, se não for cumprido. Difere do SLO, que é a meta interna e mais rígida. O SLA de um serviço da AWS vale para o serviço, não para a sua aplicação, cuja disponibilidade depende da composição dos componentes.
