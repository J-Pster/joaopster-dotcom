# Migracao Heterogenea

A migração heterogênea troca o motor do banco no caminho (por exemplo, Oracle para PostgreSQL). Exige converter esquema e código com a Schema Conversion Tool ou o DMS Schema Conversion, além de mover os dados com o DMS. Existe quando a empresa quer sair de licenças caras ou adotar um serviço gerenciado.

> [!example] Exemplo
> Oracle migrado para Aurora PostgreSQL com conversão de esquema e DMS.
