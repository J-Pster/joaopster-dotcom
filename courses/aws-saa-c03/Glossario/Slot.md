# Slot

Slot é cada dado que um intent precisa para ser cumprido, como data, tamanho ou cidade. O Amazon Lex pergunta ao usuário o que falta até preencher todos os slots obrigatórios e só então chama o fulfillment. Existe para transformar uma frase solta em dados estruturados.

> [!example] Exemplo
> No intent ReservarHotel, os slots são cidade, data de entrada e número de noites.
