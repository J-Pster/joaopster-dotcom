# EBS Snapshots Archive

O EBS Snapshots Archive é uma camada de armazenamento de menor custo para snapshots que você raramente precisa restaurar, com retenção mínima de 90 dias e restauração em até 72 horas. Move o snapshot completo para a camada arquivo. Existe para guardar snapshots mensais, trimestrais ou anuais por muito tempo, pagando menos.

> [!example] Exemplo
> O snapshot de fim de ano é arquivado por sete anos por exigência de auditoria, sem custo da camada padrão.
