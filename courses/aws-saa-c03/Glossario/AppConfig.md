# AppConfig

O AWS AppConfig, capacidade do Systems Manager, implanta configuração de aplicação e feature flags de forma gradual e validada, com rollback automático se um alarme disparar. Existe para mudar configuração sem reimplantar o código.

> [!example] Exemplo
> Uma feature flag é liberada para 10% dos usuários e revertida sozinha se os erros subirem.
