# WorkSpaces

O Amazon WorkSpaces é o serviço de desktops virtuais gerenciados (DaaS) da AWS, que entrega um desktop Windows ou Linux na nuvem, acessível de vários dispositivos. Existe para o time não comprar nem manter desktops físicos: os dados ficam na AWS e a cobrança pode ser mensal ou por hora. A prova o escolhe quando o cenário pede desktops remotos seguros, como trabalho remoto ou prestadores externos, e não servidores de aplicação.

> [!example] Exemplo
> Uma empresa dá a prestadores externos um WorkSpace com acesso aos sistemas internos, sem enviar notebook nem deixar dados na máquina deles.
