# SSML

SSML é uma linguagem de marcação (parecida com XML) para controlar como o texto vira fala: pausas, ênfase, velocidade, tom e pronúncia. Existe porque o texto puro não diz como ele deve ser falado. O Amazon Polly aceita SSML nas requisições de síntese.

> [!example] Exemplo
> Inserir uma pausa de meio segundo antes do preço em um anúncio falado usa uma marca SSML.
