# S3 Tables

O S3 Tables é a oferta gerenciada de tabelas Apache Iceberg no S3, com compactação automática e integração com Athena e EMR.

> [!example] Exemplo
> Um lake com atualizações frequentes usa S3 Tables em vez de gerenciar Iceberg à mão.
