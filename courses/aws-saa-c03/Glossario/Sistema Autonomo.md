# Sistema Autonomo

Rede sob uma única administração, identificada por um número (ASN), que troca rotas com outras pelo BGP. O AS path é a lista de sistemas autônomos que um caminho atravessa, usado como critério de escolha.

> [!example] Exemplo
> O seu data center e a AWS são sistemas autônomos diferentes que trocam rotas por BGP.
