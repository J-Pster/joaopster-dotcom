# Application Discovery Service

O Application Discovery Service coleta dados de servidores locais (configuração, uso de CPU e memória, conexões de rede) para ajudar a planejar uma migração. Existe porque migrar bem exige saber o que há no ambiente e quais servidores conversam entre si. A documentação atual indica que ele está fechado para novos clientes, com o AWS Transform como sucessor (verificado em novembro de 2026).

> [!example] Exemplo
> Antes de planejar as ondas, a equipe usa os dados de dependência para descobrir que o servidor de aplicação depende de um banco antigo.
