# Workgroup do Redshift Serverless

No Redshift Serverless, o workgroup agrupa os recursos de computação (RPUs, sub-redes, security groups), enquanto o namespace agrupa os objetos de banco. Não confunda com o workgroup do Athena.

> [!example] Exemplo
> Um workgroup de 32 RPUs ligado a um namespace de relatórios.
