# Distrator

Distrator é cada alternativa errada de uma questão de múltipla escolha. Na prova da AWS, os distratores são serviços reais que resolvem outro problema, configurações quase certas ou soluções que funcionam, mas custam mais ou exigem mais operação que o pedido. Reconhecer o tipo de distrator acelera a eliminação.

> [!example] Exemplo
> Oferecer Shield Standard para bloquear SQL injection é um distrator: o serviço existe e protege, mas quem bloqueia SQL injection é o WAF.
