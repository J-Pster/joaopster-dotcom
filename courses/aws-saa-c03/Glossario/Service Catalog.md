# Service Catalog

Serviço que permite à organização publicar um catálogo de produtos aprovados, como modelos de infraestrutura, para os times provisionarem por conta própria. Equilibra autonomia e governança. É uma forma de distribuir padrões sem revisar cada pedido manualmente.

> [!example] Exemplo
> A equipe de plataforma publica um produto de banco de dados já configurado e criptografado, e os times o provisionam em poucos cliques.
