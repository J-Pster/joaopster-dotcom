# Patch Group

Patch group é um agrupamento de nós por tag (chave Patch Group) que os associa a uma patch baseline específica. Permite políticas diferentes para homologação e produção.

> [!example] Exemplo
> Instâncias com Patch Group igual a prod usam a baseline conservadora.
