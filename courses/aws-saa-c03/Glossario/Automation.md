# Automation

O Automation do Systems Manager executa runbooks: fluxos de várias etapas, com aprovação e ramificação, que agem em serviços AWS. É usado para tarefas operacionais repetíveis e para a remediação automática disparada por EventBridge ou AWS Config.

> [!example] Exemplo
> Um runbook para a instância, cria uma AMI e a reinicia depois da aprovação de um operador.
