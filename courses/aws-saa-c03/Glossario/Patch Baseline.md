# Patch Baseline

Patch baseline é o conjunto de regras que define quais correções são aprovadas para instalação (por classificação, gravidade e idade). A AWS oferece baselines predefinidas por sistema operacional, e você pode criar as suas.

> [!example] Exemplo
> A baseline de produção aprova correções críticas com 7 dias de idade.
