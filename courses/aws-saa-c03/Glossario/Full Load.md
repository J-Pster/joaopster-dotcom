# Full Load

A carga completa (full load) é a etapa em que o DMS copia todos os dados existentes das tabelas de origem para o destino. Existe como ponto de partida da migração; depois dela, o CDC mantém o destino atualizado com as mudanças.

> [!example] Exemplo
> Uma tabela de 500 GB é copiada integralmente na primeira fase da tarefa do DMS.
