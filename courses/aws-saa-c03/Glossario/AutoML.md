# AutoML

AutoML é a técnica que automatiza etapas do machine learning, como escolher o algoritmo e ajustar parâmetros, a partir dos dados rotulados que você fornece. Existe para que quem tem dados, mas pouca experiência em ciência de dados, ainda consiga um modelo próprio. Na AWS aparece no SageMaker Autopilot, no Rekognition Custom Labels e no Comprehend personalizado.

> [!example] Exemplo
> Uma equipe envia uma planilha de clientes ao SageMaker Autopilot e recebe um modelo de previsão de cancelamento sem escolher o algoritmo.
