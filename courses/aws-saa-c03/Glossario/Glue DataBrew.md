# Glue DataBrew

O Glue DataBrew é a ferramenta visual e sem código de preparação de dados do Glue: analistas limpam e normalizam dados com receitas prontas. Existe para quem não escreve Spark.

> [!example] Exemplo
> Um analista remove duplicatas e padroniza datas de um CSV por receitas, sem programar.
