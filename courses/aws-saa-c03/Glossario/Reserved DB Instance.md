# Reserved DB Instance

A reserved DB instance é um desconto de cobrança, por 1 ou 3 anos, para uma combinação de Região, engine e classe de instância. Ela existe para reduzir o custo de bancos que rodam 24 horas por dia. Não é uma instância física: o desconto se aplica às instâncias que correspondem à reserva.

> [!example] Exemplo
> Um RDS for PostgreSQL de produção estável recebe uma reserva de 3 anos para a mesma classe.
