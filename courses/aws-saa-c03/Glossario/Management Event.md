# Management Event

Evento do CloudTrail sobre operações de gerenciamento nos recursos da conta, como criar uma sub-rede, anexar uma política IAM ou criar uma trail. Também inclui eventos que não são de API, como o login no console. Trails registram esse tipo por padrão.

> [!example] Exemplo
> A criação de um security group aparece como evento de gerenciamento, sem nenhuma configuração extra.
