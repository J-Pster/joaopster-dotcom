# Armazenamento de Objetos

O armazenamento de objetos guarda cada dado como um objeto com chave, conteúdo e metadados em um espaço plano, acessado por uma API HTTP. Não há hierarquia real de pastas nem alteração parcial: um objeto é regravado inteiro. Existe para guardar quantidades enormes de dados com durabilidade altíssima e custo baixo, servidos pela internet.

> [!example] Exemplo
> Milhões de fotos de usuários guardadas no S3 e servidas por URL.
