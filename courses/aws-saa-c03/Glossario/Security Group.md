# Security Group

O security group é o firewall virtual stateful que atua na interface de rede do recurso. Só tem regras de permitir, avalia todas as regras em conjunto, bloqueia por padrão toda entrada e deixa a resposta de um tráfego permitido sair sozinha. Pode referenciar outro security group como origem, o que acompanha o Auto Scaling e aplica menor privilégio, e a prova o contrasta com a network ACL, que é stateless e permite negar.

> [!example] Exemplo
> O banco aceita TCP 5432 somente do security group da aplicação, e não de um CIDR.
