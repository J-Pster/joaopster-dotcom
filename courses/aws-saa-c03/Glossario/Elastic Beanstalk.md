# Elastic Beanstalk

Serviço de plataforma que implanta e gerencia aplicações web a partir do código, criando por baixo os recursos de EC2, balanceador e Auto Scaling. Serve para quem quer subir uma aplicação sem montar a infraestrutura. Os recursos criados continuam visíveis e ajustáveis.

> [!example] Exemplo
> Um time envia o pacote de uma aplicação Node.js ao Elastic Beanstalk e ele cria as instâncias, o balanceador e o grupo de Auto Scaling.

Veja também: [[Auto Scaling Group]], [[EC2]], [[Elastic Load Balancing]], [[Lambda]]
