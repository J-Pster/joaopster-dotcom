# State Manager

O State Manager mantém os nós gerenciados em um estado desejado por meio de associações (documento, alvos e agenda). Existe para reaplicar a configuração de forma contínua, como garantir que um agente esteja instalado.

> [!example] Exemplo
> Uma associação reinstala o CloudWatch Agent a cada 30 minutos se alguém removê-lo.
