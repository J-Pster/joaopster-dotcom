# Snowball Edge

O Snowball Edge é um dispositivo físico robusto e criptografado que a AWS envia ao cliente para copiar terabytes de dados e devolvê-lo, ou para processar dados em locais sem conectividade. Existe porque, em volumes muito grandes, enviar discos é mais rápido do que a rede. A documentação atual indica que ele está fechado para novos clientes (verificado em novembro de 2026).

> [!example] Exemplo
> Uma empresa com 200 TB e link lento pede dispositivos Snowball Edge para a carga inicial no S3.
