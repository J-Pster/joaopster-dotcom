# DMS Schema Conversion

O DMS Schema Conversion é o recurso do DMS (no console) que converte esquemas e código de banco de um motor para outro, com o apoio de IA generativa em partes do processo. Existe como alternativa à Schema Conversion Tool instalada na máquina, para migrações heterogêneas, e deixa um relatório do que não pôde ser convertido automaticamente.

> [!example] Exemplo
> Um esquema Oracle é convertido para Aurora PostgreSQL, e o relatório lista procedimentos que exigem ajuste manual.
