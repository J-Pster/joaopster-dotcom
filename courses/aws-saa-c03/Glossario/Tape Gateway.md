# Tape Gateway

O Tape Gateway apresenta uma biblioteca de fitas virtuais (VTL) por iSCSI para o software de backup, guardando as fitas no S3 e podendo arquivá-las no S3 Glacier. Existe para trocar fitas físicas sem mudar o processo de backup.

> [!example] Exemplo
> Uma empresa substitui o robô de fitas por um Tape Gateway, mantendo o mesmo software de backup.
