# Well-Architected Tool

Serviço gratuito da AWS para revisar uma workload contra o Framework: o time responde perguntas, a ferramenta aponta riscos e gera um plano de melhoria. Serve para transformar a revisão em um processo repetível, com histórico. Ela organiza o trabalho, mas não corrige nada sozinha.

> [!example] Exemplo
> O time cadastra a workload de pedidos, responde às perguntas do lens padrão e recebe uma lista de riscos altos e médios para tratar.
