# Nota Escalonada

Nota escalonada é a pontuação da prova convertida por um modelo estatístico para uma escala de 100 a 1.000, que equaliza formas de prova com dificuldades ligeiramente diferentes. Na SAA-C03, o mínimo para aprovação é 720. Como não existe conversão publicada para número de acertos, 720 não equivale a 72%.

> [!example] Exemplo
> Dois candidatos com o mesmo número de acertos em formas diferentes da prova podem receber notas escalonadas diferentes.
