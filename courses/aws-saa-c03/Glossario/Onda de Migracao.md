# Onda de Migracao

Uma onda de migração é um grupo de aplicações e servidores migrados juntos, normalmente por terem dependências entre si. Existe para dividir um grande projeto em etapas controláveis, aprendendo com cada uma antes da próxima.

> [!example] Exemplo
> A primeira onda leva aplicações simples e independentes, e as seguintes vão para as mais críticas.
