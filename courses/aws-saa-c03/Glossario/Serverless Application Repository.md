# Serverless Application Repository

O Serverless Application Repository é um catálogo gerenciado para encontrar, implantar e publicar aplicações serverless, públicas ou privadas, integrado ao console do Lambda. Cada aplicação é descrita por um template SAM, e implantar uma aplicação do catálogo cria seus recursos na sua conta. Serve para reaproveitar soluções prontas e compartilhar as suas dentro de uma equipe ou organização.

> [!example] Exemplo
> Uma equipe encontra no catálogo um aplicativo pronto de processamento de logs, revisa o template e o implanta com alguns parâmetros em vez de escrever as funções do zero.
