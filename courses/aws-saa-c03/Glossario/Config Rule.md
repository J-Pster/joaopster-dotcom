# Config Rule

Regra do Config que representa a configuração ideal e avalia os recursos, marcando-os como conformes ou não conformes. Pode ser gerenciada (da AWS), personalizada (com Lambda), vinculada a serviço ou organizacional. A avaliação roda por mudança de configuração, periodicamente ou das duas formas.

> [!example] Exemplo
> Uma regra gerenciada marca como não conforme todo volume EBS sem criptografia.
