# Intent

Intent é a intenção que o usuário quer realizar em uma conversa, como reservar um quarto ou consultar um saldo. É o conceito central do Amazon Lex: o bot reconhece qual intent a frase expressa e então coleta os dados necessários (slots). Separar intenções torna o bot previsível e fácil de testar.

> [!example] Exemplo
> As frases 'quero uma pizza' e 'pede uma pizza grande' ativam o mesmo intent PedirPizza.
