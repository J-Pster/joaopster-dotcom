# EKS Anywhere

O EKS Anywhere é um produto gerenciado pelo cliente para criar e operar clusters Kubernetes no próprio data center, inclusive em ambientes isolados (air-gapped), construído sobre o EKS Distro. Aqui o plano de controle e os nós ficam com você, com suporte AWS por assinatura. Escolha-o quando o Kubernetes precisa rodar fora da nuvem com a mesma base do EKS.

> [!example] Exemplo
> Um órgão com rede isolada opera clusters Kubernetes locais com suporte da AWS.
