# Well-Architected Lens

Extensão do Framework com perguntas e boas práticas para um tipo específico de carga ou setor, como serverless ou SaaS. Existe porque o Framework geral não cobre os detalhes de cada tecnologia. A Well-Architected Tool aplica um ou mais lenses a cada workload.

> [!example] Exemplo
> Uma equipe que roda funções Lambda aplica o lens de serverless além do lens padrão, para receber perguntas sobre cold start e limites de concorrência.
