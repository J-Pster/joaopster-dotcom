# Systems Manager

Conjunto de ferramentas para operar frotas de recursos: executar comandos, aplicar patches, guardar parâmetros e automatizar procedimentos. Existe para substituir o acesso manual por rotinas repetíveis. Apoia operações como código.

> [!example] Exemplo
> O time aplica um patch em centenas de instâncias com um documento de automação, sem abrir sessões SSH.
