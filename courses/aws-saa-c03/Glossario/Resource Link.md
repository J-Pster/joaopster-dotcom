# Resource Link

No Lake Formation, um resource link é um ponteiro no seu catálogo para um banco ou tabela compartilhado de outra conta ou Região. Existe para consultar sem copiar dados nem metadados, inclusive acesso entre Regiões.

> [!example] Exemplo
> Um link em eu-west-1 aponta para a tabela de us-east-1, e o Athena a consulta de lá.
