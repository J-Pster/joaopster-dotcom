# Valkey

Motor de dados em memória de código aberto, derivado do Redis, usado pelo ElastiCache e pelo MemoryDB. É compatível com os clientes e comandos do Redis na prática, então a migração costuma ser simples.

> [!example] Exemplo
> A equipe escolhe o Valkey ao criar um cache serverless no ElastiCache.
