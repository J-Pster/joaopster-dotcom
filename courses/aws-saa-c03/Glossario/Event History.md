# Event History

Registro pesquisável e imutável dos últimos 90 dias de eventos de gerenciamento do CloudTrail em uma Região, disponível sem configuração e sem custo. Não inclui eventos de dados e não é um registro permanente. Para guardar por mais tempo, é preciso criar uma trail.

> [!example] Exemplo
> Para investigar uma mudança de ontem, a equipe consulta o Event history no console, sem trail configurada.
