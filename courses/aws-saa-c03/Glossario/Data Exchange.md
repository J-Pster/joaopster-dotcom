# Data Exchange

O AWS Data Exchange é o marketplace para assinar conjuntos de dados de terceiros e recebê-los na AWS (arquivos, APIs, Redshift ou S3). Existe para evitar negociar e transferir dados por conta própria.

> [!example] Exemplo
> Uma empresa assina dados de clima e os recebe direto em um bucket S3.
